# Breast Cancer Classification using Machine Learning

## 📌 Objective
To apply supervised learning techniques on the breast cancer dataset and compare different classification algorithms.

## 📊 Dataset
The dataset is taken from sklearn's built-in breast cancer dataset.

## ⚙️ Algorithms Used
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- k-Nearest Neighbors (KNN)

## 🔧 Steps Performed
- Data Loading
- Data Preprocessing
- Feature Scaling
- Model Training
- Model Evaluation

## 📈 Results
- Best Model: SVM (~98%)
- Worst Model: Decision Tree / KNN (~94%)

## ✅ Conclusion
SVM performed the best due to its ability to handle high-dimensional data effectively.
